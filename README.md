## Olist Lakehouse

Pipeline de dados end-to-end em arquitetura medalhão (Bronze → Silver → Gold) construído no Databricks Free Edition, usando o dataset público Olist Brazilian E-Commerce.

Projeto criado com fins de aprendizado, cobrindo os fundamentos de engenharia de dados em um ambiente lakehouse moderno: Delta Lake, PySpark, SQL, Unity Catalog, orquestração de jobs, lineage e (como bônus) pipelines declarativos.
